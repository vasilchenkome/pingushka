# Changelog

## v0.2.3

### English

- Replaced browser datalist tag entry with a searchable combobox that supports keyboard navigation, explicit creation, duplicate prevention and the ten-tag limit.
- Standardized native dropdown styling and improved touch target sizes across filters, forms and bulk actions.
- Reflowed agent assignment choices for narrow screens and clarified connection status.
- Improved dialogs with contained scrolling, keyboard focus management and focus restoration; destructive actions now use clear confirmation UI.
- Removed nested interactive controls from target rows and labelled context-sensitive actions for assistive technology.

### Русский

- Заменили ввод тегов через браузерный datalist на поиск с клавиатурной навигацией, явным добавлением, защитой от дублей и лимитом в десять тегов.
- Привели нативные выпадающие списки к единому виду и увеличили зоны нажатия в фильтрах, формах и массовых действиях.
- Адаптировали выбор агентов для узких экранов и сделали статус подключения понятнее.
- Улучшили диалоги: прокрутка остаётся внутри, клавиатурный фокус удерживается и возвращается после закрытия; опасные действия требуют явного подтверждения.
- Убрали вложенные интерактивные элементы в строках целей и добавили контекстные подписи действий для вспомогательных технологий.
